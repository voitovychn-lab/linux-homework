# Домашнє завдання №5 — Terraform

Войтович Назар

У цьому проєкті описано інфраструктуру AWS за допомогою
Terraform. Код розділено на три модулі: s3-backend, vpc та ecr.

Регіон AWS — us-west-2.

## Структура проєкту

- main.tf — підключення модулів і налаштування AWS.
- backend.tf — налаштування збереження стейту в S3.
- outputs.tf — виведення результатів.
- modules/s3-backend — S3-бакет і таблиця DynamoDB.
- modules/vpc — мережа, підмережі, шлюзи та маршрути.
- modules/ecr — репозиторій для Docker-образів.

## Опис модулів

### s3-backend

Створює S3-бакет для стейту Terraform.
У бакеті ввімкнено версіювання.
Таблиця DynamoDB використовується для блокування стейту.

### vpc

Створює VPC, три публічні та три приватні підмережі.
Для публічних підмереж використовується Internet Gateway,
а для приватних — один NAT Gateway.
Маршрути налаштовані через таблиці маршрутизації.

### ecr

Створює репозиторій для Docker-образів.
Увімкнено сканування образів під час завантаження.
Додано політику доступу для поточного AWS-акаунта.
URL репозиторію виводиться через outputs.tf.

## Підготовка

Потрібно встановити Terraform та AWS CLI,
а також налаштувати доступ до AWS.

Назва S3-бакета має бути унікальною.
У main.tf і backend.tf потрібно вказати однакову назву.

Команди виконуються з папки lesson-5.

## Перший запуск

Спочатку код у backend.tf має бути закоментований,
оскільки S3 та DynamoDB ще не створені.

Підготовка та перевірка коду:

```bash
terraform fmt -recursive
terraform init
terraform validate
```

Створення S3 та DynamoDB:

```bash
terraform plan -target=module.s3_backend
terraform apply -target=module.s3_backend
```

Після цього потрібно розкоментувати налаштування
в backend.tf та перенести стейт у S3:

```bash
terraform init -migrate-state
```

Створення решти ресурсів:

```bash
terraform plan
terraform apply
```

## Наступні запуски

Якщо бекенд уже створений:

```bash
terraform init
terraform plan
terraform apply
```

## Видалення ресурсів

Перед видаленням S3 та DynamoDB потрібно повернути стейт
на комп’ютер:

1. Закоментувати код у backend.tf.
2. Виконати terraform init -migrate-state і підтвердити перенесення.
3. Переконатися, що локальний terraform.tfstate містить ресурси.
4. Очистити S3-бакет через AWS Console, включно з версіями файлів
   і маркерами видалення.
5. Видалити образи з ECR, якщо вони були завантажені.

Після цього виконати:

```bash
terraform destroy
```

Після повного видалення повторний запуск виконується
за інструкцією «Перший запуск».

Файли стейту та ключі AWS не потрібно додавати до GitHub.

## Перевірка

Виконано terraform init і terraform validate.
Перевірка конфігурації завершилася успішно.
